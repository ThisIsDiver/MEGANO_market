# ИСХОДНЫЙ КОД ДЛЯ САЙТА MEGANO

---
### Немного о проекте

Данный проект разделяется на frontend-приложение и на DRF-приложение, которое является API для frontend. 
market_api_app полностью отталкивается от frontend и принятых в нём решений. 

---
### Подготовка

Сделайте клон репозитория или скачайте папку src.

В корневой папке у вас лежит .env-example. Переименуйте его в .env и поменяйте логины, пароли, название базы данных

---
### Как запустить?

Запустите контейнер с помощью
```bash
docker compose up --build
```

Скопируйте выданный системой логин и пароль. По завершению будет создана база данных PostgreSQL, в которой будет храниться вся информация.

Перейдите на http://localhost:8000/ или если не на хосте http://[IP-address]:8000/

## ПЕРЕД ЗАПУСКОМ В ```settings.py``` ОТКЛЮЧИТЬ DEBUG ЗАМЕНИВ НА ```False```
